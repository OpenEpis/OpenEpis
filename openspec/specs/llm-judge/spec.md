## ADDED Requirements

### Requirement: LLM Judge scoring function

The system SHALL provide an `llmJudge` function that accepts a scenario goal description and agent output, calls the LLM, and returns a 0-1 score with reasoning.

The judge call SHALL use the same LLM config as the agent (read from `LLM_CONFIG_*` environment variables), calling the OpenAI-compatible API directly.

#### Scenario: Normal scoring

- **WHEN** called with goal="agent should generate BDD related to shopping cart" along with the agent's reply text and BDD output
- **THEN** returns `{ score: number, reasoning: string }` where score is in the 0.0-1.0 range and reasoning is non-empty

#### Scenario: Graceful degradation on malformed LLM response

- **WHEN** the LLM returns content that cannot be parsed as `{ score, reasoning }` JSON
- **THEN** the function SHALL return `{ score: 0, reasoning: "Judge parse error: ..." }` without throwing an exception

### Requirement: Judge prompt template

The system SHALL use a unified judge prompt template containing the following placeholders:

- `{goal}`: Scenario evaluation goal description
- `{agent_reply}`: Agent's text reply
- `{tool_calls}`: List of tools called by the agent (JSON)
- `{bdd_output}`: BDD structure generated by the agent (JSON)

The judge prompt SHALL instruct the LLM to return results in JSON format.

#### Scenario: Complete prompt assembly

- **WHEN** goal, agent_reply, tool_calls, and bdd_output are all provided
- **THEN** the generated prompt contains all four fields and explicitly requires JSON `{ score, reasoning }` response

### Requirement: Judge config loading

The system SHALL read LLM config from environment variables: `LLM_CONFIG_PROVIDER`, `LLM_CONFIG_MODEL`, `LLM_CONFIG_API_KEY`, `LLM_CONFIG_BASE_URL` (optional).

When required config is missing, it SHALL throw an error with a clear message.

#### Scenario: Complete config

- **WHEN** environment variables `LLM_CONFIG_PROVIDER`, `LLM_CONFIG_MODEL`, `LLM_CONFIG_API_KEY` are all set
- **THEN** the system can correctly construct an LLM API request

#### Scenario: Missing config

- **WHEN** any required environment variable is missing
- **THEN** an error is thrown with a message containing the missing variable name
